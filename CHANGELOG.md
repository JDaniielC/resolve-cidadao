## Template History

This project started as a fork of the [Godot 2D Top-Down Template](https://github.com/stesproject/godot-2d-topdown-template) by Stefano Mercadante.

**Original Template Features Used:**
- State machine architecture
- Character controller system
- Interaction area system
- Dialogue Manager integration
- Scene management framework

**Modifications for Resolve Cidadão:**
- Content reoriented for educational narrative
- Focus on citizen rights and public services
- Recife-specific locations and culture
- Educational dialogue choices
- Satisfaction/impact system
